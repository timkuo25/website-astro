一款以大學生活為主題的視覺小說遊戲

## 安裝

[Link](https://github.com/timkuo25/UniLife)

平台：Windows

   ```bash
   git clone https://github.com/timkuo25/UniLife
   pip install pygame
   python game5.py
   ```

## 操作方式

| 畫面 | 按鍵 | 功能 |
| --- | --- | --- |
| 開始畫面 | `N` | 開始新遊戲 |
| 開始畫面 | `1` / `2` / `3` | 讀取存檔 1 / 2 / 3 |
| 遊戲中 | `D` | 下一句 |
| 遊戲中 | `A` | 上一句 |
| 遊戲中 | `Esc` | 開啟存檔選單 |
| 存檔選單 | `1` / `2` / `3` | 存到存檔 1 / 2 / 3 |
