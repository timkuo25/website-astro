A college-life visual novel game.

## Install

[Link](https://github.com/timkuo25/UniLife)

Platform: Windows

   ```bash
   git clone https://github.com/timkuo25/UniLife
   pip install pygame
   python game5.py
   ```

## Controls

| Screen | Key | Action |
| --- | --- | --- |
| Start screen | `N` | Start a new game |
| Start screen | `1` / `2` / `3` | Load save slot 1 / 2 / 3 |
| In game | `D` | Next line |
| In game | `A` | Previous line |
| In game | `Esc` | Open the save menu |
| Save menu | `1` / `2` / `3` | Save to slot 1 / 2 / 3 |
