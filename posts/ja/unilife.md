大学生活をテーマにしたビジュアルノベルゲーム

## インストール

[Link](https://github.com/timkuo25/UniLife)

プラットフォーム：Windows

   ```bash
   git clone https://github.com/timkuo25/UniLife
   pip install pygame
   python game5.py
   ```

## 操作方法

| 画面 | キー | 動作 |
| --- | --- | --- |
| タイトル画面 | `N` | ニューゲーム |
| タイトル画面 | `1` / `2` / `3` | セーブデータ 1 / 2 / 3 をロード |
| ゲーム中 | `D` | 次のセリフ |
| ゲーム中 | `A` | 前のセリフ |
| ゲーム中 | `Esc` | セーブメニューを開く |
| セーブメニュー | `1` / `2` / `3` | セーブデータ 1 / 2 / 3 に保存 |
